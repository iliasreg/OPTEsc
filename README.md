# OPTEsc

Your AI guide for optimal escape routes in urgent situations.

## Development

Install [uv](https://docs.astral.sh/uv/getting-started/installation/), then run:

```sh
uv sync --locked
uv run --frozen pre-commit install
uv run --frozen pre-commit run --all-files
```

Python 3.12 · Ruff lint/format · GitHub Actions · Dependabot
